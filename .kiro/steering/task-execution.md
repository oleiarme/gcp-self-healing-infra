# Выполнение задач через субагентов

При выполнении задач из spec (tasks.md) всегда делегируй реализацию через субагентов (`invoke_sub_agent` с агентом `spec-task-execution` или `general-task-execution`), а не выполняй задачи напрямую в основном контексте.

Это позволяет:
- Сохранять основной контекст чистым для оркестрации
- Параллелизировать независимые задачи
- Изолировать ошибки реализации от навигации по плану
